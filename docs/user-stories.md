# User Stories

- As a business owner, I can record an expense so my register stays current.
- As a bookkeeper, I can upload an invoice and correct extracted values before saving.
- As a reviewer, I can see whether OCR data was confirmed.
- As a user, I can search by supplier or description and open full details.
- As a manager, I can see spend and GST totals calculated from saved records.
- As a maintainer, I can replace mock OCR without changing route logic.
