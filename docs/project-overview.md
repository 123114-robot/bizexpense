# Project Overview

Australian SMEs often collect expense data in receipts, email and spreadsheets, making GST reporting and record lookup slow. BizExpense provides one minimal flow: capture an expense manually or from a document, verify it, store it and see totals. The MVP proves the workflow and clean extension points without pretending to solve production OCR, identity or accounting sync.

Success means a developer can run it locally, complete the workflow end to end, and test business rules in isolation.
